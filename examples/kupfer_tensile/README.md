# KupferDigital tensile-to-neural workflow

This case uses CuSn8Ni2 specimens H_08, H_16 and H_18 from
[KupferDigital, version 2](https://doi.org/10.5281/zenodo.10820299).
Place the public `Files.zip` in a local source directory and retain its
CC-BY-4.0 attribution. Source `Content.pdf` describes the materials, testing
procedure, specimen geometry and measured properties.

H_08 supplies the effective elastic slope and bilinear plastic calibration.
H_16 checks the calibrated model, and H_18 is the final experimental holdout.
The numerical model is a homogeneous square gauge with measured initial area
and gauge length, under a small-strain approximation up to 0.8% axial strain.
This represents the uniform gauge response of the cylindrical specimen.
Poisson ratio is an explicit modeling choice with two sensitivity runs.

The completed case includes a [reference INP](reference/base.inp),
[figures and experimental comparison](../../docs/verification/2026-09-06-public-tensile-surrogate.md)
and a [machine-readable result summary](../../docs/verification/assets/public-tensile-20260906/summary.json).
The reference uses mm, MPa, N and s. Its calibrated material values derive from
the cited CC-BY-4.0 source and its mesh was generated by this project.

## Run the stages

Install the code and optional training/plot dependencies:

```text
python -m pip install -e ".[native,training]" matplotlib
```

Copy `runtime.example.json` to a local file and set `abaqus_command` to the
command tokens for your installed Abaqus environment. Run from the project root:

```text
python examples/kupfer_tensile/prepare.py --source-dir <source-directory> --output-dir <new-case-directory> --runtime-config <local-runtime.json>
python examples/kupfer_tensile/run_cases.py --case-dir <case-directory>
python examples/kupfer_tensile/train_evaluate.py --case-dir <case-directory>
python examples/kupfer_tensile/plot_results.py --case-dir <case-directory>
```

Preparation creates calibrated parameters and twelve small case configurations.
Each uses one CPU, with a 300-second timeout per Abaqus stage. The case runner
performs validation, INP generation, datacheck, analysis, ODB extraction and
HDF5/NPZ export, followed by an axial-response check. `--cases base` selects one
case. A repeated invocation continues from recorded completed stages.

Five parameter cases train the MLP, two select its checkpoint and two evaluate
the fixed model. All rows from a case share its split. The three additional
cases check Poisson-ratio sensitivity and an eight-element mesh. The calibration
curve and the experimental holdouts retain separate roles.

## Outputs

The case directory contains `sources/`, `configs/`, `jobs/`, `model/` and
`figures/`. Every completed job has `input/model.inp`,
`solver/analysis/gauge.odb`, `dataset/sample.h5`, `dataset/sample.npz`,
`dataset/axial-response.npz` and stage reports. The model folder contains the
checkpoint, training history and predictions.

`evaluation.json` gives separate FE/analytical, neural/FE and model/experiment
errors. `experimental-comparison.csv` records the common strain grid and all
three stress curves. Figures show the calibration/holdout comparisons and the
neural training/test results. Numerical sensitivity results refer to the stated
homogeneous gauge model and its axial response.

The preprocessing origin is the first recorded strain/stress pair. A strictly
increasing initial loading subsequence is interpolated on a fixed grid.
`source-records.json` retains selected original rows and these transformations.
The case reports nominal stress increments in MPa and engineering strain from
that preload origin.
