## KupferDigital tensile case: CC-BY-4.0

Source: *KupferDigital mechanical testing datasets: Brinell hardness, Vickers
hardness, and tensile tests*, version 2, 15 March 2024.

Authors: Hossein Beygi Nasrabadi, Felix Bauer, Ladji Tikana, Patrick Uhlemann,
Steffen Thärig, Birgit Rehmer and Birgit Skrotzki.

Source DOI: https://doi.org/10.5281/zenodo.10820299

License: Creative Commons Attribution 4.0 International (CC-BY-4.0),
https://creativecommons.org/licenses/by/4.0/ (legal text:
https://creativecommons.org/licenses/by/4.0/legalcode).

The following files are distributed under CC-BY-4.0, including this project's
figure composition, computed comparisons and generated reference model:

- `docs/verification/assets/public-tensile-20260906/experimental-workflow.png`
- `docs/verification/assets/public-tensile-20260906/neural-validation.png`
- `docs/verification/assets/public-tensile-20260906/summary.json`
- `examples/kupfer_tensile/reference/base.inp`

The case selects CuSn8Ni2 specimens H_08, H_16 and H_18. Processing subtracts
the first recorded strain/stress pair, selects the increasing initial loading
subsequence within 0–0.8% engineering strain, interpolates onto fixed grids,
and fits a small-strain bilinear isotropic-plastic model to H_08. H_16 checks
the model and H_18 supplies the final experimental evaluation. The reference
mesh is generated by this project using the source area and gauge length;
FE and MLP predictions and comparison metrics are project computations.

These are processed case materials. The original `Files.zip`, `Content.pdf`
and instrument files are obtained from the source record and kept locally.
Reuse of the processed files should retain this attribution, license link
and processing description. The source authors do not endorse this project.

## External references and optional inputs

`configs/public_sources/ntnu_ri_27daafa.json` identifies an optional fixed
revision of NTNU's crystal-plasticity input bundle and records its MIT license.
The repository contains the source manifest, with the referenced UMAT and
input files obtained separately. Keep the upstream license with those files.

Other datasets discussed in the native-adapter verification are references
to local read checks. Their original files are obtained separately under
their respective source terms.

## Python dependencies and external tools

Dependencies declared in `pyproject.toml` are installed separately. Their
distributions carry their own license texts and any bundled-library notices.
The wheel and sdist contain this project's Python implementation and resources.
Abaqus and its Python/ODB runtime are supplied by the user's licensed installation.
