# GH4169 接入与评估计划

本计划执行用户已授权的 GH4169 单一数据源接入；在当前任务内依次实施，保留本地修改，未经本任务授权不提交或发布。

数据依据：Mendeley DOI 10.17632/v487vwmd7r.1 的 DATA.xlsx，Sheet1 A4:J13；原论文 DOI 10.1016/j.ndteint.2019.05.003 的公开 Material microstructure 段确认十个 GH4169 试样。工作簿有八个 NO. 编号及 T1/T2，每个试样一行汇总值。Sheet2/3 空白，数值均为常量。原文件已与公开清单摘要核对。

## 已确定的设计

- 输入固定为 D 列平均衰减系数（dB/mm）和 F 列平均纵波声速（m/s）；C 列为金相平均晶粒直径（μm）。不依据目标相关系数选列，不采用作者融合特征、拟合系数或预测结果。H/J 等列的定义/数值疑点和 B9/B10 原文异常保留在审查记录中。
- 通过现有 XLSX block 适配器，每个试样建立一个 SamplePackage/HDF5；记录 A 列试样身份、B 列原热处理文字、C/D/F 原数值和 source_sheet/source_row。原表、JPG、转换后数据和权重仅放 runs/ 忽略目录。
- TrainingInput 增加可选 target_specimen（column、evidence），仅支持具有原生表块、原列映射和已核验逻辑转换链的表目标。选中目标行中的试样身份必须等于 group。根文件 URI/hash 不变。来源检查同时检查试样身份和物理工作表/行；未声明范围时保持整文件规则。混合范围与整文件、同试样或重叠源行跨划分均拒绝。训练核心和 train/validation/test 至少两行约束不变。
- 开发试样固定成四对：NO.1/NO.5、NO.2/NO.6、NO.3/NO.7、NO.4/NO.8；按编号制定，不按目标调分组。外层每次保留一对，剩余六个试样内三次 4/2 的训练/验证，验证选 checkpoint，三个固定模型平均预测外层两个试样。这样开发集每个预测均来自未用其目标训练或选 checkpoint 的模型。
- 最终四个 MLP 各用 6/2/2（训练/验证/T1+T2）构建；验证选 checkpoint 后四模型等权平均。固定 hidden=[4]、seed=17、learning_rate=0.003、epochs=1500、patience=200。外层估计的训练规模小于最终模型，分别解释。
- 均值和 OLS 基线只拟合相应训练开发集。岭回归 alpha 候选为 0.01、0.1、1、10、100，内层验证选 alpha，再用完整外层训练开发集拟合；最终只用八个开发样本的四折验证选择 alpha。所有标准化在相应拟合子集计算。
- 不将八个开发试样的内层验证预测当成独立泛化指标；主指标为开发集外层预测和两件最终测试试样的 MAE/RMSE，逐试样保存预测与误差。MLP 与岭回归不是作者 MUE 的复现。
